# 하루숨

> 힐링 프로그램 소개 웹페이지 | 웹 디자인·퍼블리싱 / 프론트엔드 포트폴리오

## 프로젝트 소개
일상에서 휴식과 여유를 느낄 수 있는 힐링 프로그램 소개 페이지를 제작했습니다. 자연 사진과 차분한 컬러를 사용해 콘텐츠 분위기를 표현했습니다.

## 사용 기술
HTML · CSS

## 주요 작업 내용

### 01. 헤더
로고와 오늘의 쉼·힐링 프로그램·리뷰·예약 메뉴를 배치했습니다.

### 02. 메인 비주얼
큰 자연 이미지 위에 휴식에 관한 문구를 배치했습니다.

### 03. 프로그램 소개
이미지와 설명 영역을 나누고 프로그램 카드 3개에 설명과 태그를 넣었습니다.

### 04. 시각적 정리
배경 위 텍스트 대비와 카드 사이 간격, 제목 크기를 조정했습니다.

## 작업하면서 익힌 내용
HTML 섹션 구조를 잡고 CSS로 이미지, 타이포그래피, 여백의 균형을 맞추는 연습을 했습니다. 배경 사진 위에서도 문장을 읽기 쉽도록 만드는 데 집중했습니다.

## 프로젝트 정리
JavaScript 기능보다는 정적인 페이지의 콘텐츠 배치와 시각적 완성도를 연습한 퍼블리싱 프로젝트입니다.
